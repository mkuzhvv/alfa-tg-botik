# Техническое задание

Версия 0.1.0. Сдать проект до 16 ноября 2026 года. Точное время отсечки берём из правил организаторов.

## Результат

Telegram-помощник для предпринимателей на базе материалов «Альфа-Курса» и адаптивный Mini App. Бот отвечает на вопросы, учитывает ситуацию бизнеса, рекомендует материалы, сохраняет план действий и отправляет напоминания. Mini App показывает план, напоминания и профиль.

Пользовательский путь: вопрос → уточнение → ответ с источниками → план → напоминание → продолжение работы.

## Функции первой версии

| Функция | Требуемое поведение |
|---|---|
| Начало работы | `/start` создаёт пользователя. Можно сразу задать вопрос без обязательной анкеты |
| Консультация | Ответ по разрешённым материалам базы, понятные действия и указание источников |
| Уточнение | При нехватке сведений бот задаёт один конкретный вопрос за ход диалога |
| Нет ответа | Бот честно сообщает о пробеле. Ошибка модели обозначается как технический сбой |
| Персонализация | Используются явно сообщённые сведения о бизнесе, текущий план и история диалога |
| Материалы | До трёх рекомендаций с объяснением пользы и существующими ссылками |
| План | Одна активная цель и три–пять шагов. У каждого шага один–два связанных материала |
| Напоминания | Один раз, ежедневно, еженедельно или ежемесячно. Изменение времени, перенос, пауза, возобновление и отмена |
| Продолжение | Бот учитывает сохранённую цель и отмеченный пользователем прогресс |

В боте план сохраняется после нажатия «Сохранить план». В Mini App пользователь может создать план из цели, указанной в запросе или профиле. Замена активного плана требует отдельного подтверждения. Прежний план архивируется при успешном сохранении нового. Отметка выполнения — сообщение пользователя, а не подтверждённое прохождение урока на сайте.

Напоминание создаётся по явному действию пользователя. Неясные дата, время и часовой пояс уточняются. После сохранения бот подтверждает точное расписание. Рекламных рассылок нет. Для бизнес-события с неизвестным сроком бот спрашивает дату; автоматический расчёт налоговых сроков в первую версию не входит.

## Mini App

| Экран | Возможности |
|---|---|
| Мой план | Создать или заменить план, открыть материалы, отметить или вернуть шаг, архивировать план |
| Напоминания | Список, создание, изменение, пауза и отмена; ближайшая отправка с часовым поясом |
| Мой бизнес | Сфера, стадия бизнеса, опыт, текущая задача, при необходимости налоговый режим и часовой пояс |

Обязательна адаптивная вёрстка для мобильного и десктопного Telegram. Проверяем ширины 360, 768 и 1280 px. Основные действия доступны, текст читаем, горизонтальной прокрутки страницы нет. Нужны состояния загрузки, пустого списка, ошибки, истёкшего входа и конфликта изменения.

Чат и Mini App используют одни данные. Консультация и управление напоминаниями доступны через чат.

## Работа команды

| Участник | Обязательный результат |
|---|---|
| Java-бэкенд | Telegram, авторизация Mini App, REST API, БД, планы, напоминания, интеграция Spring AI, импорт знаний и Docker |
| ML 1 | Сборка и очистка знаний, каталог, фрагменты текста, embedding-модель и качество поиска |
| ML 2 | Генеративная модель, инструкции, персонализация, уточнения, предложения действий и качество ответов |
| Фронтенд | Адаптивные три экрана, формы и состояния, работа с API |

ML передаёт подготовленные материалы и настройки. Исполнение пользовательских действий и хранение состояния находятся в Java. Фронтенд отображает данные сервера и отправляет команды через API.

## Данные и ограничения

- Исходный бэкап восстанавливается в `alfa_source`. Данные приложения и подготовленные знания хранятся в `assistant`.
- Используем готовые модели и RAG. Обучение собственной языковой модели не входит в первую версию.
- `Cost = NULL` означает бесплатный курс. Публикация и закрытость проверяются отдельно.
- Платные материалы рекомендуются по разрешённому описанию; подробный закрытый текст не раскрывается.
- Во внешние API передаются только разрешённые необходимые фрагменты без персональных данных. Это правило действует и для embeddings.
- Выгрузка, подготовленный корпус и реальные ключи не публикуются в Git и публичных образах.
- Обезличенная история Альфы автоматически не связывается с Telegram-пользователями.

## Готовность

1. Новый пользователь получает ответ по существующему источнику, а неопределённый вопрос приводит к уточнению.
2. Отсутствующая информация не выдумывается; технический сбой не маскируется под отсутствие знаний.
3. Рекомендации используют существующие материалы и не раскрывают закрытое содержание.
4. План можно сохранить из чата или создать из Mini App. Для замены требуется подтверждение. При ошибке генерации текущий план остаётся доступен, прогресс одинаков в обоих интерфейсах.
5. Напоминание действительно приходит. Повторение меняется, приостанавливается и отменяется. Ежемесячное напоминание на 31-е учитывает длину месяца и сохраняет число для следующего расчёта.
6. Перезапуск сохраняет профили, планы и расписания; повтор Telegram-события не создаёт дубли.
7. Пользователь не получает чужие данные. Интерфейс работает на мобильной и десктопной ширине.
8. Проект запускается по README через Docker с предоставленными данными и нужными ключами.
