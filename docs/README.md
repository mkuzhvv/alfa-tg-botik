Подготовлены запуск Java и PostgreSQL с Flyway, проверка здоровья и внутренние
сервисы пользователя и бизнес-профиля. На шаге 3.2 добавлены Telegram-клиент,
настройки запуска и проверка подключения через `getMe`. На шаге 3.3 подключены
long polling и личный `/start` с сохранением пользователя и профиля. На шаге 3.4
добавлены `/help`, меню команд, кнопка помощи и понятные ответы на неподдержанные
сообщения. На шаге 3.5 добавлены постоянный учёт событий, сохранённые ответы и
ограниченные повторы доставки. Действие и ответ сохраняются до обращения к Telegram;
повтор одного события не выполняет действие заново. Проверки этапа 3 описаны в
заметках по реализации. На этапе 4 реализованы вход по подписанному Telegram `initData`,
сессии в памяти на 8 часов, выход, защита API через Spring Security,
`GET /me`, `PATCH /me/profile` и общий формат ошибок с идентификатором запроса.
Проверки и ограничения интеграции с настоящим Mini App описаны в заметках по реализации.
На этапе 5 добавлены проверка поставки ML 1, версионный каталог, атомарный импорт,
API карточки материала и внутренний поиск через локальную embeddinggemma/Spring AI/pgvector.
Проверки механики и приёмка качества поиска разделены; команды приведены в заметках по реализации.
Реальная локальная поставка импортирована и технически проверена. Приёмка качества
по контрольным вопросам ожидает приватный набор ML 1.
На этапе 6 добавлены сохранение и подтверждённая замена плана, прогресс шагов,
архив, версии и защищённые API чтения/изменения. На этапе 7 подключены Quartz и
доставка напоминаний, на этапе 8 — локальная консультация через Spring AI/Ollama.
На этапе 9 добавлены проверенное пополнение профиля, предложения плана и напоминания
с подтверждением, команды просмотра/управления в Telegram и `POST /plans/generate`
с идемпотентностью и подтверждённой заменой. Проверки и ограничения — в заметках по реализации.
На этапе 10 frontend подключён к API: вход, профиль, планы, напоминания и обработка
ошибок; добавлены контейнер nginx и настройка меню Mini App. Запуск и браузерные
проверки описаны в frontend/README.md. Временный HTTPS настроен через localhost.run
без регистрации; пользователь подтвердил открытие в Telegram и синхронизацию профиля
между Mini App и чатом при включённом Happ TUN.
Структуру своих папок и внутреннее устройство инструментов фронтендер и ML-разработчики определяют самостоятельно в рамках этих контрактов.
