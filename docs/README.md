# Документы проекта

Версия 0.1.0. Эти документы задают границы первой версии проекта. Владелец требований и контрактов — автор проекта, Java-бэкенд-разработчик. Команда реализует описанные интерфейсы; изменения границ вносит владелец.

| Документ | Кто использует |
|---|---|
| [Техническое задание](PROJECT_SPEC.md) | Вся команда: результат, функции, ответственность и готовность |
| [Архитектура](ARCHITECTURE.md) | Бэкенд и все, кто подключает свои части |
| [Общие правила контрактов](contracts/README.md) | Вся команда |
| [API Mini App](contracts/FRONTEND_API.md) | Фронтенд и бэкенд |
| [OpenAPI](contracts/backend.openapi.yaml) | Методы и типы API, импорт в инструменты разработки |
| [Подготовка знаний](contracts/data/README.md) | ML 1 и бэкенд |
| [Работа с моделью](contracts/llm/README.md) | ML 2 и бэкенд |

Подготовлен минимальный запуск Java и PostgreSQL с Flyway и проверкой здоровья.
Пользовательские функции пока не реализованы. Инструкции запуска находятся в корневом README.
Структуру своих папок и внутреннее устройство инструментов фронтендер и ML-разработчики определяют самостоятельно в рамках этих контрактов.
