Приложение состоит из Telegram-бота, Mini App и Java API. PostgreSQL хранит профиль, историю диалога, планы, напоминания и поисковый индекс. Java вызывает локальные модели через Spring AI/Ollama; доставку напоминаний выполняет Quartz.

Для запуска используйте RUNBOOK.md, для ручной проверки — DEMO.md. Материалы Python-прототипа RAG описывают инструменты ML и отдельный путь экспериментов; рабочий бот не требует Python worker.
