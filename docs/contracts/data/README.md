# Контракт ML 1 и бэкенда

Версия 0.1.0. ML 1 передаёт подготовленный корпус, бэкенд импортирует его и строит индекс через Spring AI. Структура кода ML остаётся на усмотрение разработчика.

## Результат поставки

В локальном `data/processed/<datasetVersion>/` находятся `manifest.json`, `materials.jsonl` и `chunks.jsonl`. JSONL — UTF-8 без BOM, одна запись на строку, без пустых строк. Поставка представляет полный снимок, а не набор изменений. Реальные файлы не публикуются в Git.

## Карточка materials.jsonl

| Поле | Тип и правило |
|---|---|
| `schemaVersion` | Строка `0.1.0` |
| `materialId` | Устойчивый UUID приложения |
| `sourceType` | ARTICLE, COURSE, LESSON, DOCUMENT, WEBINAR, PODCAST, GLOSSARY, CALCULATOR |
| `sourceId` | Исходный UUID |
| `title` | Строка до 250 символов |
| `description` | Разрешённое краткое описание до 1000 символов или null |
| `url` | Подтверждённый абсолютный HTTPS-адрес |
| `isPaid` | Boolean |
| `sourceCost` | Исходное целое Cost или null; поле обязательно для COURSE, для остальных только при наличии в источнике |
| `answerAllowed` | Boolean: допустим ли текст материала для ответов |
| `externalMetadataAllowed` | Boolean: допустимо ли передать краткую карточку внешнему API |
| `duration` | Исходная понятная подпись до 100 символов или null |
| `topics`, `industries` | Массивы нормализованных строк; при отсутствии пустые |
| `parentMaterialIds` | UUID связанных курсов; при отсутствии пустой массив |
| `sourceUpdatedAt` | UTC или null |

`materialId` вычисляется как UUIDv5 с namespace `a1fa0000-0000-4000-8000-000000000001` и именем `sourceType + ":" + sourceId`.

## Фрагмент chunks.jsonl

| Поле | Тип и правило |
|---|---|
| `schemaVersion` | Строка `0.1.0` |
| `chunkId` | UUIDv5: namespace `a1fa0000-0000-4000-8000-000000000002`, имя `materialId + ":" + order` |
| `materialId` | UUID карточки из той же поставки |
| `order` | Порядковый номер фрагмента от 1 внутри материала |
| `heading` | Заголовок раздела до 250 символов или null |
| `text` | Очищенный текст, 30–6000 символов |
| `contentHash` | SHA-256 UTF-8 текста, 64 символа lowercase hex |
| `externalTextAllowed` | Boolean: можно ли передать фрагмент внешнему API |

## Правила подготовки

- Тексты статей собираются из `ArticleEmbedItems`, уроков — из `LessonEmbedItems`, документов — из `DocumentEmbedItems`, глоссария — из `GlossaryEmbedItems`. Сохраняется порядок `Order`; полезные тексты из `Params` тоже извлекаются.
- Для каталога используются исходные карточки, описания и связи. Ссылка на видео/файл не считается готовым текстом его содержимого.
- Удаляются оформление, баннеры, скрипты, base64 и служебные данные. Заголовки, списки и смысл таблиц сохраняются.
- Удалённые, неопубликованные, закрытые и неясные по доступности материалы исключаются.
- Для поля Cost: NULL и 0 дают `isPaid=false`, положительное значение — `true`, отрицательное отклоняется. При отсутствии поля доступ определяется подтверждёнными настройками сущности. Права урока учитывают связанные курсы; неоднозначность требует исключения текста.
- Платная карточка содержит только разрешённое описание и `answerAllowed=false`. Полные платные тексты в chunks не передаются.
- Фрагменты создаются только для бесплатных материалов с `answerAllowed=true`. Для бесплатного видео без текста допустимо `answerAllowed=false`.
- Неизвестный URL не конструируется наугад: материал исключается с указанием причины. Для урока допустима подтверждённая страница курса.
- Неизвестное разрешение внешней передачи означает false. Фильтр применяется и до embeddings, и до LLM.
- ML 1 выбирает разбиение по смысловым разделам; ориентир 300–700 токенов, верхний предел 6000 символов. Параметры фиксируются в отчёте.

## Manifest и импорт

Manifest содержит `schemaVersion`, `datasetVersion`, `createdAt`, `sourceSnapshot`, `materialsCount`, `chunksCount`, `materialsSha256`, `chunksSha256`. Контрольные суммы считаются по полным байтам файлов.

ML 1 передаёт также отчёт: причины исключения материалов, пустые тексты, неизвестные ссылки, параметры разбиения и результаты проверки поиска. Бэкенд проверяет поля, ID, связи, хеши и права. Ошибка отклоняет снимок с указанием файла и строки; частичный снимок не становится активным.

Повтор версии с теми же суммами ничего не дублирует, другие суммы под прежней версией отклоняются. После полной загрузки и индексации новый снимок становится активным. Отсутствующие в новом снимке старые фрагменты перестают использоваться.

Embeddings вычисляются Java через Spring AI по выбранной ML 1 модели. Название, версия и размерность сохраняются вместе с версией индекса. При смене модели индекс перестраивается. ML 1 отвечает за качество нахождения нужных источников, а не только за факт загрузки текста.
